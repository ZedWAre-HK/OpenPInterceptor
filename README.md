# OpenPInterceptor

本项目由最初加密的末影珍珠防空炮脚本（[PInterceptor.java](./PInterceptor.java)）进行反编译与还原所得（[OpenPInterceptor.java](./OpenPInterceptor.java)），由 **ZedWAre** 完成逆向还原。

> ⚠️ **注意**：目前尚未在游戏内进行实际测试确认可否正常使用；如果遇到无法使用或异常问题，请联系我进行修复。

## 项目简介

- **原脚本信息**：`By Adnin | Predictive pearl interception (experimental)`
- **逆向与还原**：`ZedWAre`（完成脚本加密层解密、事件回调与全部接口符号还原）
- **核心功能**：末影珍珠轨迹采样与预测、1.8.9 原版加速/恒速火球弹道拦截求解、通道体素碰撞检测、反向急停（Counter Brake）、静默转头与发包冲突保护、预测轨迹 2D/3D 可视化渲染。
